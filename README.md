# في السكة · Fel Sekka

تطبيق مواصلات بالموتوسيكلات: اشتراك شهري أو مشوار واحد، تفاوض على السعر، تتبع مباشر، وشات مع الكابتن.
فيه **سكة الشباب** و**سكة البنات** — البنت بتركب مع كابتن بنت بس، والشكل كله بيتغيّر حسب المستخدم (سماوي نيون للشباب، فوشيا نيون للبنات).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
npm run lint     # فحص TypeScript
```

## البوابات

| البوابة | الرابط | فيها |
|---|---|---|
| الراكب | `#/home` | طلب مشوار (4 خطوات)، تفاوض، تتبع مباشر، شات، تقييم، مشاويري، تنبيهات |
| الكابتن | `#/captain` | تسجيل ورفع المستندات، أونلاين/أوفلاين، قبول/رفض/اقتراح سعر، شات، اشتراك InstaPay |
| **لوحة الإدارة (تطبيق منفصل)** | `admin.html` | لوحة قيادة ورسوم بيانية، مراجعة طلبات الكباتن بقائمة تحقق ومستندات بتتكبّر، قبول/رفض بسبب، إيقاف كابتن، تأكيد InstaPay، الركاب، المشاوير، الخطوط، الإعدادات |

التطبيقين بيتبنوا من نفس الكود (`npm run build` بيطلّع `dist/index.html` و`dist/admin.html`) وبيقروا ويكتبوا في نفس البيانات،
فأي كابتن يبعت بياناته بيظهر في لوحة الإدارة لحظياً، وأول ما الأدمن يقبله التطبيق عند الكابتن بيتحدث.

## قاعدة البيانات (Supabase)

التطبيق ولوحة الإدارة متوصلين بمشروع Supabase واحد (`src/lib/config.ts`)، فأي حاجة بتحصل في واحد بتظهر في التاني لحظياً من أي جهاز.

- **الجداول والصلاحيات:** `supabase/schema.sql` — بيتشغّل مرة واحدة من SQL Editor (آمن تعيد تشغيله).
- **الحماية:** كل مستخدم بيشوف بياناته بس (Row Level Security)، ومستندات الكباتن في مخزن خاص مايشوفهوش غير الكابتن نفسه والأدمن، وكل العمليات المهمة (القبول، تأكيد الدفع، الحجز) بتتنفذ على السيرفر.
- **الأدمن:** أول حساب يفتح `admin.html` ويختار كلمة سر بيبقى الأدمن الوحيد.
- **تسجيل الدخول:** برقم الموبايل وكلمة السر. لازم يكون **Confirm email مقفول** في Authentication → Sign In / Providers.

## قبل الإطلاق

1. **`src/lib/config.ts`**: غيّر `INSTAPAY_HANDLE` و`SUPPORT_WHATSAPP` ببياناتك الحقيقية، وراجع الأسعار.
2. **التتبع الحقيقي**: الخريطة دلوقتي محاكاة متحركة. للتتبع الحقيقي محتاج الكابتن يبعت موقعه + خرائط (Google Maps / Mapbox).

## الهيكل

```

  screens/    Onboarding · Auth · client/ · captain/
  admin/      لوحة الإدارة (main · AdminApp · Overview · Applications · Captains · Pages · kit)
```
